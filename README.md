# Standard Calculator (Python + Tkinter)

A fully featured, Windows‑style Standard Calculator built with Python and Tkinter.  
This project replicates the behavior, layout, and user experience of the Windows 10/11 Standard Calculator, including history, memory functions, immediate‑execution logic, and a polished UI.

---

## ✨ Features

- Modern Windows‑style UI using Tkinter
- Two‑line display (expression + result)
- Full operator support: `+`, `−`, `×`, `÷`
- Immediate‑execution logic (like Windows Calculator)
- Repeated equals (`=`) behavior
- History panel with clickable entries
- Memory panel with:
  - `MC`, `MR`, `M+`, `M−`, `MS`
  - Hover‑activated memory buttons
- Clean modular architecture:
  - `gui_calculator.py` – UI and event handling
  - `operations.py` – math logic and memory
  - `style.py` – colors, fonts, themes
  - `ui_components.py` – reusable widgets
- Fully debuggable with VS Code (launch.json included)
